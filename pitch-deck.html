Vibe Drive Jersey

Drive around a real map of Jersey — live weather, real restaurants, actual day/night

Your island. Your vibe. Your steering wheel.

vibe.je hackathon · Good Vibes #2 · 20 Aug 2026

What is it?

  • 🗺️ Real OpenStreetMap of Jersey, centred on St Helier
  • 🚗 Drive a car with touch controls — works on iPad & iPhone
  • 🌤️ Live weather from Open-Meteo — real temperature, wind, conditions
  • 🌙 Day/night cycle from actual Jersey sunrise/sunset times
  • 🍽️ 12 real Jersey restaurants with food.je links
  • 🚤 Boat & Fly modes coming soon

Why Jersey?

12m
tidal range — one of the world's largest
  • 🇯🇪 Real local data — Jersey weather, Jersey tides, Jersey restaurants
  • 📍 Built for the vibe.je community — this is OUR island
  • 🔗 food.je integration — drive past a restaurant, tap to order

Built in 45 minutes

  • ⚡ Vanilla JS + Leaflet.js — no framework, no build step
  • 🌐 OpenStreetMap tiles — free, no API key
  • 🌦️ Open-Meteo API — free, real-time weather
  • 🌅 Sunrise-sunset.org API — free, actual sun position
  • 🔌 Tailscale Funnel — public HTTPS from homelab, zero cloud cost
No API keys No build step No cloud bill No install
