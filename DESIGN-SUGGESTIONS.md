## Part 1: 3D Driving Game (`index.html`)

### 1.1 — Color Scheme: Replace Generic Blue with Jersey Brand

**Problem:** The HUD uses `rgba(10,10,30,0.75)` with generic blue accents (`#4466ff`, `#6688ff`, `rgba(100,130,255,...)`). None of the brand colors (Jersey Green `#00A86B`, Atlantic Blue `#0A1A3F`, Sprint Yellow `#FFD60A`, Rally Red `#E63946`) appear in the HUD at all.

**Fix — Define CSS custom properties at the top of `<style>`:**

```css
:root {
  --jersey-green: #00A86B;
  --atlantic-blue: #0A1A3F;
  --sprint-yellow: #FFD60A;
  --rally-red: #E63946;
  --hud-bg: rgba(10, 26, 63, 0.82);          /* Atlantic Blue at 82% opacity */
  --hud-border: rgba(0, 168, 107, 0.25);      /* Jersey Green border tint */
  --hud-accent: rgba(0, 168, 107, 0.6);       /* Jersey Green accent */
  --text-primary: #F0F4FF;
  --text-secondary: rgba(240, 244, 255, 0.55);
  --text-muted: rgba(240, 244, 255, 0.35);
}
```

**Replace all generic blue references:**

| Current value | Replace with | Context |
|---|---|---|
| `rgba(10, 10, 30, 0.75)` | `var(--hud-bg)` | HUD, score-display, toast, ad-popup backgrounds |

| `rgba(100, 130, 255, 0.3)` | `var(--hud-accent)` | Mode buttons, cam buttons, control buttons borders |

### 1.12 — iPad Safari Specific Optimizations

1. **`-webkit-backdrop-filter` is already used** — good. Ensure all glass elements have both `backdrop-filter` and `-webkit-backdrop-filter`.

2. **`100dvh` is already used** for the canvas — excellent for iPad Safari's dynamic viewport.

3. **Touch target minimum sizes**: iPad accessibility guidelines recommend 44×44px minimum. The pill buttons at 76×52px exceed this. Keep the 76×52 size. The cam buttons at ~50×24px are **too small** for touch. Increase cam button padding to `padding: 8px 12px` to exceed 44px height.

4. **Prevent double-tap zoom** — already handled via `user-scalable=no` in viewport meta. Good.

5. **`-webkit-tap-highlight-color: transparent`** — already set in `*` selector. Good.

6. **Safe area insets** for iPad with notch/rounded corners:

```css
#hud {
  top: max(12px, env(safe-area-inset-top));
  left: max(12px, env(safe-area-inset-left));
}

#modes {
  top: max(12px, env(safe-area-inset-top));
  right: max(12px, env(safe-area-inset-right));
}

#controls {
  padding-bottom: max(24px, env(safe-area-inset-bottom));
  padding-left: max(20px, env(safe-area-inset-left));
  padding-right: max(20px, env(safe-area-inset-right));
}

#radar {
  bottom: max(24px, env(safe-area-inset-bottom));
  left: max(12px, env(safe-area-inset-left));
}
```

7. **Performance**: `backdrop-filter: blur()` is GPU-expensive on iPad Safari. With 6+ elements using blur simultaneously, consider reducing blur radius from `12px` to `8px` on all elements, or use `blur(6px)` for the smaller elements (cam buttons, control buttons).

8. **Prevent Safari address bar show/hide jitter**: The `100dvh` canvas already handles this. Ensure no element uses `100vh` instead of `100dvh`.

### 1.13 — Overall Visual Polish Checklist

- [ ] Replace all `border-radius` values with `0` for HUD elements (angular brand language)
- [ ] Keep `border-radius: 26px` (pill) ONLY for control buttons
- [ ] Add `box-shadow: 0 4px 20px rgba(0,0,0,0.4)` to all floating HUD panels for depth
- [ ] Add a subtle Jersey Green left-border accent (`border-left: 3px solid var(--jersey-green)`) to the HUD and score display

- [ ] Ensure all glass elements have consistent blur (use `--blur-amount: 10px` variable)

Add JS to animate when slide becomes active:

```js
// Add to the show() function, after setting active slide:
function animateBigStat(slide) {
  const stat = slide.querySelector('.big-stat');
  if (!stat) return;
  const target = parseInt(stat.dataset.target || '12');
  let current = 0;
  stat.textContent = '0m';
  const interval = setInterval(() => {
    current += 1;
    stat.textContent = current + 'm';
    if (current >= target) {
      clearInterval(interval);
      stat.textContent = target + 'm';
    }
  }, 80);
}

// In show(n), after slides[n].classList.add('active'):
animateBigStat(slides[n]);
```
